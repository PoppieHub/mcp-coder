# mcp-coder v0.1.0

The first public release of **mcp-coder**: a lightweight Go MCP server that delegates well-scoped implementation work to a separate coding model while the primary agent keeps control of planning, decisions, and final review.

## Highlights

- **Focused delegation** — send concrete coding, testing, refactoring, and documentation tasks to an Anthropic Messages-compatible model.
- **Bounded edits** — constrain each task with suggested files and `allowedChangePaths`.
- **Project-aware context** — discover repository instructions, manifests, modules, package managers, test frameworks, and declared verification commands.
- **Verification before completion** — require successful checks for every module and language containing changed code.
- **Safe parallel execution** — run independent tasks concurrently while preventing overlapping scopes and simultaneous edits to claimed files.
- **Reviewable results** — return changed files, a bounded diff, verification evidence, warnings, usage, and the last failed check when a task does not complete.
- **Hardened workspace access** — reject path traversal, symlink escapes, secret files, arbitrary shell execution, and Git mutations.
- **Prompt-cache support** — use cache markers when supported and automatically fall back when a gateway rejects them.

## MCP tools

The release includes synchronous and background task execution, task status and cancellation, project-stack discovery, read-only model questions, runtime settings, and diagnostics.

## Supported platforms

Prebuilt archives are published for:

- Linux: amd64 and arm64
- macOS: Intel and Apple Silicon
- Windows: amd64 and arm64

Every archive contains the `mcp-coder` binary, README, and Apache-2.0 license. `SHA256SUMS` is included with the release assets.

## Requirements

`mcp-coder` requires your own model endpoint compatible with the Anthropic Messages API and these environment variables:

- `MCP_LLM_TOKEN`
- `MCP_LLM_BASE_URL`
- `MCP_LLM_MODEL`

Run `mcp-coder doctor` after installation. Use `doctor --api` to verify the model and tool-use round trip.

## Integrations

Setup instructions are included for Claude Code, Claude Desktop, and OpenAI Codex. The stdio MCP transport also works with other MCP-compatible hosts.
