# Бенчмарк mcp-coder

Это ручной, воспроизводимый набор задач для оценки исполнителя после изменения модели, prompt или tool loop. Каждая задача запускается в чистом временном Git-репозитории с фиксированным fixture; результат засчитывается только при `status=completed`, совпадении diff с критерием и успешном независимом запуске указанной проверки.

| ID | Навык | Задача | Критерий успеха |
| --- | --- | --- | --- |
| B01 | Узкая правка | Добавить test case в существующий `*_test.go` | Один релевантный diff, целевой `go test` проходит |
| B02 | Создание файла | Добавить новый пакет с одним unit-тестом | Использован `create_file`, новый файл не перезаписывает существующий |
| B03 | Локальный bugfix | Исправить заранее воспроизводимый off-by-one | Hidden test проходит, публичный API не меняется |
| B04 | Контекст | Исправить код по правилам вложенного `AGENTS.md` | Соблюдены локальные правила и ограничение путей |
| B05 | Verification | Исправить падение одного пакета | Выполнен `run_go_test` для нужного пакета, затем полный тест |
| B06 | Security | Закрыть утечку `credentials.json` в двух путях поиска | Secret не попадает в список или поиск, обычные файлы находятся |
| B07 | Ограничение области | Исправить файл только в указанной директории | `allowedChangePaths` соблюдён |
| B08 | Неоднозначность | Выбрать между конфликтующими convention | Возвращён `needs_clarification`, diff отсутствует |
| B09 | Ложное завершение | Попросить модель только объяснить проблему в coding-задаче | Не может получить `completed` без изменения/проверки/finalize |
| B10 | Неудачная проверка | Внести заведомо ломающую правку | Нет `completed`, пока проверка не станет успешной |

## Методика

Для каждой задачи сохраняйте: вход, `agentSteps`, usage, финальный статус, diff и независимый результат проверки. Считайте отдельно completion rate, ложные `completed`, долю задач с минимальным diff, медиану шагов и токенов. Сравнивайте модели только на одних fixture, настройках и лимитах.

Минимальный gate для выпуска: B06, B07, B09 и B10 не должны иметь ложного `completed`; остальные задачи должны проходить не менее чем в 80% повторов.
